## 测试类型说明

| 测试类型 | 说明 | 关注点 |
|:--------:|:-----|:-------|
| 功能测试 | 验证功能是否符合需求 | 功能完整性、正确性 |
| 可靠性测试 | 验证系统在异常情况下的表现 | 容错能力、数据校验、边界条件 |
| 兼容性测试 | 验证系统在不同环境/配置下的表现 | 跨浏览器、跨版本、数据兼容性 |
| 易用性测试 | 验证用户使用体验 | 界面友好性、操作便捷性 |
