# Proposal

## Problem

当前平台缺少一个集中展示平台热度的概览页面，用户无法快速了解：
- 各类别工具的热门程度
- 各类别帖子的讨论热度
- 平台整体统计数据（用户数、帖子总数、工具总数）

用户需要一个一目了然的仪表盘式页面来快速获取平台概况。

## Testable Behaviors

- WHEN 用户访问概览页 THEN 页面展示各类型工具热榜（TOP 10）
- WHEN 用户访问概览页 THEN 页面展示各类型帖子热榜（TOP 10）
- WHEN 用户访问概览页 THEN 页面展示平台统计卡片（用户总数、帖子总数、工具总数）
- WHEN 用户点击工具类别 THEN 页面跳转至对应类别的工具列表
- WHEN 用户点击帖子类别 THEN 页面跳转至对应类别的帖子列表
- WHEN 数据加载中 THEN 显示骨架屏加载状态
- WHEN 数据加载失败 THEN 显示错误提示并提供重试按钮

## Acceptance Criteria

1. 概览页面包含三个主要模块：工具热榜、帖子热榜、统计卡片
2. 工具热榜按类别分组，每个类别展示 TOP 10
3. 帖子热榜按类别分组，每个类别展示 TOP 10
4. 统计卡片实时展示用户总数、帖子总数、工具总数
5. 所有数据通过后端 API 获取
6. 页面加载时显示骨架屏
7. 错误状态有友好的错误提示和重试机制
8. 响应式布局适配桌面和移动端
