可访问性检查

  • 纯图标按钮有 aria-label（编辑/删除）
  • 焦点环：暗色 #00FFFF / 亮色 #7c3aed，offset 2px
  • 删除按钮白字 on #EF4444 对比度 4.7:1 (AA)
  • prefers-reduced-motion 关闭动画
  • 键盘可达：Tab 循环、Esc 关闭对话框、Enter 触发
  • 确认对话框 role="dialog" + aria-modal="true"
