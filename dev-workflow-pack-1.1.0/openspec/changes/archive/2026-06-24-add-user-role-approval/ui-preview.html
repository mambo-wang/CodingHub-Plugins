6. 可访问性检查

  • ✅ 所有按钮有文字标签或 aria-label
  • ✅ RoleSelector 使用 role="radiogroup" + role="radio" + aria-checked
  • ✅ 错误提示使用 role="alert"
  • ✅ 暗色焦点环 #00FFFF / 亮色焦点环 #7c3aed
  • ✅ 状态徽章用颜色+文字双通道表达
  • ✅ prefers-reduced-motion 已处理
  • ✅ 表格移动端可横向滚动
