6. 可访问性 (a11y) 检查

依据 MASTER.md 和 WCAG 2.1 AA 验证。

  • 对比度 — 删除 #EF4444 在暗色 4.7:1 ✅ AA / 亮色 4.5:1 ✅ AA
  • 焦点环 — 所有按钮 :focus-visible 输出 2px var(--focus-ring)，双主题适配
  • 语义标签 — ConfirmDialog 含 role="dialog" + aria-modal="true" + aria-labelledby
  • 图标按钮 — 纯图标按钮有 aria-label；装饰图标有 aria-hidden="true"
  • 键盘导航 — 所有按钮可通过 Tab 到达，focus-visible 可见
  • 加载状态 — loading 时 disabled + aria-busy="true"
  • Toast — 成功/错误均有 role="alert" 候选；左色条区分
  • prefers-reduced-motion — 已添加 @media 阻断动画
