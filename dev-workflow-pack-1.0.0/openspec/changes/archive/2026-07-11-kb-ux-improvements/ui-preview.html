Accessibility (a11y) Checklist

  • ☑ Download button has aria-label="Download document"
  • ☑ Delete button has aria-label="Delete document"
  • ☑ Decorative icons have aria-hidden="true"
  • ☑ Focus ring: dark #00FFFF / light #7c3aed, offset 2px
  • ☑ Disabled buttons have disabled attribute + opacity: 0.4
  • ☑ Color contrast passes WCAG AA
  • ☑ prefers-reduced-motion disables transitions
