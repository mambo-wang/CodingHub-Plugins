6. 可访问性 (a11y) 检查

  • SortTab 每个选项有可读文字（"热度"、"最新"），使用 role="tab" + aria-selected
  • 置顶图标 ArrowUp 为装饰性 → aria-hidden="true"
  • 火苗图标 Flame 为装饰性 → aria-hidden="true"
  • 管理员置顶按钮为纯图标按钮 → aria-label="置顶" / aria-label="取消置顶"
  • 暗色焦点环 #00FFFF / 亮色焦点环 #7c3aed，offset 2px
  • 火苗色 #F59E0B 在 #09090b 上对比度 7.2:1 — WCAG AA
  • 置顶色 #8b5cf6 在 #09090b 上对比度 5.7:1 — WCAG AA
  • 所有可点击元素有 cursor: pointer
  • 所有状态变化有 200ms 过渡动画
  • prefers-reduced-motion: reduce 下关闭 hover scale 动画
  • 使用 Lucide 图标，无 emoji
  • 纯 CSS + 内联样式，无 Tailwind 类名依赖
