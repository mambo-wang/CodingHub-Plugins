# Proposal

## Problem

当前论坛功能存在以下问题：
1. 顶部菜单栏始终显示"上传工具"按钮，用户体验不佳
2. 未登录用户无法访问论坛，限制了内容的传播
3. 缺少收藏功能，用户无法保存感兴趣的帖子

## Testable Behaviors

### 菜单栏行为
- WHEN 用户访问首页（无论登录状态）THEN 顶部菜单栏显示"工具"和"论坛"两个导航项
- WHEN 用户访问首页（无论登录状态）THEN 顶部菜单栏不显示"上传工具"按钮
- WHEN 未登录用户点击"论坛"THEN 跳转到论坛列表页面
- WHEN 未登录用户浏览论坛THEN 可以查看帖子列表和详情
- WHEN 未登录用户点击帖子点赞按钮THEN 提示"请先登录"
- WHEN 已登录用户点击帖子点赞按钮THEN 成功点赞

### 收藏功能行为
- WHEN 已登录用户点击帖子收藏按钮THEN 成功收藏帖子
- WHEN 未登录用户点击帖子收藏按钮THEN 提示"请先登录"
- WHEN 已登录用户点击"我的收藏"THEN 显示该用户收藏的所有帖子
- WHEN 未登录用户点击"我的收藏"THEN 提示"请先登录"

### 左侧导航栏行为
- WHEN 用户访问论坛页面THEN 左侧显示导航栏，包含"我的帖子"和"我的收藏"
- WHEN 未登录用户点击"我的帖子"THEN 提示"请先登录"
- WHEN 未登录用户点击"我的收藏"THEN 提示"请先登录"
- WHEN 已登录用户点击"我的帖子"THEN 显示该用户发布的所有帖子

## Acceptance Criteria

1. 顶部菜单栏移除"上传工具"按钮
2. 未登录用户可以访问论坛，浏览帖子列表和详情
3. 未登录用户可以查看帖子并点击点赞（提示登录）
4. 已登录用户可以收藏帖子
5. 论坛页面左侧显示"我的帖子"和"我的收藏"导航
6. 未登录用户点击"我的帖子"或"我的收藏"时提示登录
