如何进入此页面

1 在任意页面，使用右上角已登录的 用户头像 + 用户名 区域（未登录时仅显示「登录 / 注册」）
↓
2 点击展开 用户下拉菜单（含「个人资料 / 论坛 / 退出登录」）
↓
3 点击 「个人资料」，路由跳转至 /me/profile，即下方个人中心

提示：可直接点击上方模拟头像体验入口——展开菜单后点「个人资料」会平滑滚动并高亮下方个人中心卡片。点赞 / 收藏 / 评论数据即展示在卡片内的「我的互动」板块。
