3. 可访问性 (a11y) 检查

  • ✅ 操作按钮均有 aria-label（表情/编辑/撤回/回复/复制代码）
  • ✅ 焦点环暗色 #00FFFF / 亮色 #7c3aed，offset 2px
  • ✅ prefers-reduced-motion 关闭 typing 动画
  • ✅ 代码复制按钮 aria-label="复制代码"
  • ✅ 禁止 v-html 渲染未净化内容（DOMPurify 兜底）
