8. 可访问性 (a11y) 检查

依据 design-system.md 第 6 节与 WCAG 2.1 AA。

  • 图标按钮 — 悬浮入口 / 发送 / 关闭均为纯图标按钮，带 aria-label
  • 对话框 — 抽屉 role="dialog" + aria-modal="true" + aria-labelledby
  • 焦点环 — 暗色 #00FFFF / 亮色 #7c3aed，2px offset，:focus-visible
  • 实时播报 — 消息列表 aria-live="polite"，新消息被屏幕阅读器朗读
  • 限流 / 超长 — 输入框错误态使用 role="alert" + aria-invalid
  • 键盘可达 — Enter 发送、Shift+Enter 换行、Esc 关闭抽屉、Tab 循环
  • 装饰图标 — 在线点 / 用户头像等非交互图标 aria-hidden="true"
  • 对比度 — 气泡文字 vs 背景满足 WCAG AA
  • prefers-reduced-motion — 已阻断抽屉滑入与消息淡入动画
