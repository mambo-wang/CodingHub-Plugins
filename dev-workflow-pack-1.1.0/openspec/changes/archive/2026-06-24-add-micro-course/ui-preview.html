7. 可访问性 (a11y) 检查

  • 所有按钮有可读文字标签或 aria-label
  • 纯图标按钮（点赞、收藏、删除）有 aria-label
  • 视频播放器区域使用 aria-label="视频播放器"
  • 暗色焦点环 #00FFFF / 亮色焦点环 #7c3aed
  • 颜色对比度满足 WCAG AA（所有文字 ≥ 4.5:1）
  • 上传错误提示使用 role="alert"
  • 装饰图标使用 aria-hidden="true"
  • prefers-reduced-motion: reduce 关闭动画
