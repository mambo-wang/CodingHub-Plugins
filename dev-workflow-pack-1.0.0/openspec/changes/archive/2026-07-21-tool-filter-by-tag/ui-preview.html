5. 可访问性 (a11y) 检查

  • 触发器使用 <button>，aria-haspopup="listbox" + aria-expanded
  • 面板 role="listbox"，选项 role="option" + aria-selected
  • 键盘操作：Enter/Space 展开，方向键导航，Esc 关闭
  • 暗色焦点环 #00FFFF / 亮色焦点环 #7c3aed，offset 2px
  • 颜色对比度满足 WCAG AA
  • prefers-reduced-motion: reduce 下关闭动画
  • 装饰图标 aria-hidden="true"
  • 卡片 TagBadge 有 role="button" + aria-label
