7. 响应式策略

完整展示所有 pills，网格 auto-fill minmax(300px)

pills 可换行，filter bar 单行自适应

8. 可访问性检查

  • ✓ 上传按钮有 aria-label="上传工具"
  • ✓ Modal 使用 role="dialog" + aria-modal="true" + aria-labelledby
  • ✓ 焦点环：暗色 #00FFFF / 亮色 #7c3aed，outline-offset: 2px
  • ✓ Pill 图标使用 aria-hidden="true"
  • ✓ 键盘可达：Tab 循环、Esc 关闭 Modal、Enter 触发
  • ✓ prefers-reduced-motion: reduce 关闭动画
  • ✓ 颜色对比度满足 WCAG AA
