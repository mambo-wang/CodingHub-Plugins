4. 可访问性 (a11y) 检查

  • logo img 含 alt，占位图标 aria-hidden
  • 统计图标 aria-hidden，数字等宽字体
  • 焦点环 暗色 #00FFFF / 亮色 #7c3aed
  • 上传错误 role="alert"
  • 骨架屏 aria-busy="true"
  • prefers-reduced-motion 关闭动画
  • 375px 统计四项完整可见，无水平滚动
  • 全部 Lucide 内联 SVG，无 emoji
